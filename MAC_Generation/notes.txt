-----------------------------------------------------------
**1. Read & clean input**
Strip spaces/newlines, remove `0x`, convert hex string to bytes.

**2. Validate header**
Check bytes 0–1 are `0xBBBB` (SOF). Check byte 2 is `0x18`, `0x19`, `0x1A`, `0x1B`, `0x1C`, or `0x20`.

**3. Determine packet layout**
Read `MsgLen` (bytes 3–4). If `len(packet) == 2 + MsgLen`, it's a complete packet. If `len(packet) == 2 + MsgLen − 8`, it's payload-only. Slice accordingly so `mac_input` is always bytes 2 → before MAC/CRC.

**4. Extract IDs and date**
Fixed offsets for all 6 packet types:
- Loco ID = bytes 7–9
- NMS ID = bytes 10–11
- Date = bytes 13–15 (DD MM YY)

**5. Fetch the key pair for that date**
Query `KMS_KEY_SETS` where `VALID_FROM ≤ packet_date ≤ VALID_TO`. Decrypt `KEY_1` and `KEY_2` with AES‑GCM + AAD (`KMS_KEY_SETS|KEY_1|{key_set_id}`).

**6. Select K_NOS (mod‑2)**
`(NMS_ID + Loco_ID) % 2` → 0 = Key 1, 1 = Key 2. No date/time logic in this step.

**7. Compute CBC‑MAC**
- Zero‑pad `mac_input` to a 16‑byte multiple.
- AES‑128‑CBC, IV = 16 zero bytes.
- Take the last 16‑byte cipher block.
- MAC_CODE = first 4 bytes of that block.

**8. Output**
Print the 4‑byte MAC_CODE and the full packet hex with the MAC inserted.
